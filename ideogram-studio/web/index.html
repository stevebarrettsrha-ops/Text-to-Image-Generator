Set up the engine

Ideogram Studio runs Ideogram 4 on this machine through ComfyUI. The first run installs ComfyUI, adds ComfyUI-Manager and KJNodes, and downloads the weights. After that it starts on its own.

No Git or Python yet? The Engine page installs them for you.
